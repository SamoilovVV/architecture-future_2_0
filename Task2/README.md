# Задание 2
Необходимо разделить систему на домены, чтобы их можно было независимо развивать без необходимости реализовывать новую логику в DWH.
## Разделение системы на домены
На текущем этапе развития компании можно выделить следующие домены:
| Домен                    | Описание                                                                  |
|--------------------------|---------------------------------------------------------------------------|
| **Medical Domain**       | Работа с клиниками (диагностика, лечение, менеджмент)                     |
| **FinTech Domain**       | Банковские транзакции, кредиты, счета, финансовая отчётность              |
| **BI Domain**            | Бизнес-аналитика, отчётность и визуалдизация                              |
| **AI Domain**            | Предиктивная и диагностическая аналитика                                  |

## Обоснование разделения системы на домены
Разделение на указанные домены основано на бизнес-логике и специалаизации данных и позволяет упростить управление и развитие каждого домена за счёт минимизации пересечений.
Каждый домен может развиваться независимо без необходимости изменения всей системы. Также в каждом домене можно будет принимать специализированные архитектурные решения, что будет способствовать ускорению разработки и улучшению масштабирования. Также будет обеспечена быстрая интеграция новых доменов для обеспечения развития бизнеса за счёт обособленных API и данных для каждого домена.
